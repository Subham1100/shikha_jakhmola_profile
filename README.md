# Shikha Jakhmola — Portfolio

Single-page portfolio for designer Shikha Jakhmola: branding, packaging, typography and editorial design.

- `index.html`: the whole site (HTML, CSS and JS in one file, no build step)
- `img/`: project images (`p*.jpg` full size, `t*.jpg` thumbnails) and `portrait.jpg`

## Run locally
Open `index.html` in a browser, or serve the folder: `python3 -m http.server`.

## Deploy on GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → `main` / root.
